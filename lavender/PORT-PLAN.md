# План порту ядра iOS (XNU) на lavender

Зразок: `ref\ios-topaz-topaz` (README, NOTES, `xnu\patches`, `tools\mkadt.py`, `shim\`).
Схема та сама: ABL → `fastboot boot` → наш шим → XNU + підроблений ADT iPhone X → корінь iOS.

## Етапи

### M1. Ядро друкує текст на екрані (мета найближча)
Потрібно:
1. **Збірка XNU** у GitHub Actions (macOS-раннер): форк `MakrSas/ios-topaz` або власний репозиторій з його `.github/workflows/xnu.yml` і `xnu/patches`. ⇒ **потрібен обліковий запис GitHub користувача** і `gh` CLI (встановлення через winget, з дозволу).
2. **Патч `lavender-hw`** поверх серії topaz (робити, коли буде CI, бо потрібне дерево XNU для контексту патча):
   - ранній консольний framebuffer: `0x9c000000`/2400 → `0x9d400000`/2340 (патчі 0010, 0012, 0142). Зручно: 0x9d400000 лежить у тому самому 32-МБ блоці 0x9c000000, тож блочне відображення з 0012 підходить як є.
   - розмір панелі 2400 → 2340 (0061, 0114: центрування канви iPhone X 1125x2436).
   - вимкнути все, що чіпає залізо topaz: UFS (0028…), тач FT5452 (0083…), модем/Wi-Fi (0113…0130), батарея/зарядка PM6125 (0091, 0148), аудіо (0144…), GPU Adreno 610 (0900…). Найпростіше: не застосовувати ці патчі або вимикати boot-аргами (`sweettouch=0` тощо).
3. Корінь: на M1 без накопичувача — ядро має дійти до «waiting for root device» або паніки з текстом на екрані. Це вже успіх.
4. Запуск: `mkadt_lavender.py` → `mkpayload.py kernel adt payload.bin --cmdline 'debug=0xc serial=3 cpus=1 keepsyms=1'` → `shim\build.ps1 -Payload payload.bin` → `fastboot boot`.

### M2. Корінь iOS з RAM-диска
- Невеликий образ (патчі 0021/0022/0024 mockfs, `rd=md0`), упакований `mkpayload.py --ramdisk`.
- ⚠️ Обмеження: ABL lavender має приймати великий Image (ядро ~30–60 МБ + ramdisk). Перевірити межу (max-download 768 МБ, але буфер розпакування ядра може бути меншим).
- Потрібен IPSW iPhone X 16.7.16 (~6 ГБ від Apple) і Linux-інструменти (apfs-fuse, hfsprogs) → WSL (встановлення з дозволу).

### M3. eMMC замість UFS
- Новий драйвер у стилі `sweet_ufs.c`: SDHCI (контролер `c0c4000.sdhci`, eMMC 5.1), «переймаємо» стан, який лишив ABL; спершу тільки читання, розділ `userdata` (mmcblk0p66, ~54.6 ГБ).
- Тоді `rd=...` на `userdata`, прошивка кореня `fastboot flash userdata` (з дозволу; стирає Android-дані, користувач знає).

### M4. Дисплей і дотик
- Дисплей: вивід через копіювання кадрів у splash-буфер (як sweet/topaz «CPU frame copy»), DSC немає — простіше за topaz.
- Дотик: Novatek NT36672A (NVT-ts) по SPI (`spi7.1`, переривання GPIO 67) — новий драйвер замість FT5452/Goodix.

### M5+. Пізніше
Частота Gold (OSM/LMh), кнопки (PM660), батарея/зарядка (PM660), Wi-Fi (WCN3990, як в останню чергу), GPU Adreno 512 (a5xx) — найдовше.

## Що потрібно від користувача (зберемо, коли дійде черга)
1. Обліковий запис GitHub (для збірки ядра). Вхід в обліковий запис робить користувач сам.
2. Дозвіл на встановлення `gh` CLI (winget).
3. Пізніше: дозвіл на завантаження IPSW (~6 ГБ) і встановлення WSL.
